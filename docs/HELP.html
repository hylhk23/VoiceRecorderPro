Voice Recorder Pro 1.0

A voice-activated sound recorder for Windows 11: it records only while someone is speaking, writes straight to disk, and lets you play, mark and cut recordings without another editor.

Getting started

  1. Press Record (the red button, or R). With Vox on, the recorder waits for sound (title shows [VOX]) and records each time you speak ([REC]).
  2. Press Stop (S). The file is saved in Documents\VRP Recordings with a name like Oct02_1.mp3.
  3. Press Play (Space) to listen. Drag the Position slider to move around.

Closing the window keeps the app running in the notification area (tray). Use File > Exit to quit. Recording continues when the window is hidden or the screen is locked, and Windows will not go to sleep while recording.

Recording phone calls, meetings or conversations may require everyone's consent where you live.

Voice activation (Vox)

When the input rises above the threshold, a new segment starts. It includes a short pre-roll (audio from just before the sound) and continues for the hang time after the last sound, so short pauses inside speech do not split a segment. Bursts shorter than the minimum segment (clicks, bumps) are thrown away.

SettingDefaultEffect
Threshold4Higher = only louder sound triggers recording. Use Options > Vox > Calibrate to measure your room.

Options > Disable Vox always records continuously; Hide Vox removes the Vox controls from the window.

Files, names and segments

Recordings are named from a pattern (default {Mon}{dd}_{n}). Tokens: {yyyy} {yy} {mm} {Mon} {Month} {dd} {HH} {MM} {SS} {n} {n3} {host} {device} {tag}. A / creates subfolders, e.g. {yyyy}/{mm}/{Mon}{dd}_{n}. Existing files are never overwritten.

Pressing Record with a file open appends a new segment to it (when the format matches); change this in Options > Recording. Segment boundaries and time stamps are stored inside the file: MP3 chapters (ID3 CHAP), WAV cue points with labels, or FLAC CHAPTER tags, so other programs can see them too.

Automatic new files: by size, after a duration, at midnight or every N hours, with no audio lost between files. While recording, data reaches the disk every second; after a crash or power cut the app offers to recover the file at the next start.

Playback and transcription

  • Auto-backspace: every time playback resumes after a pause it steps back 2 s (Options > Playback).
  • Speed: 50–200% with the pitch kept (Control > Playback Speed).
  • PgUp/PgDn jump between segments; Home/End to the start/end.
  • With a selection, Play plays only the selection; Edit > Loop Selection repeats it.

Editing

Set an In mark ([) and an Out mark (]) while listening, or Shift-drag on the Position slider. Then:

CommandKeysResult
Extract Selection to FileCtrl+ENew file name_x1.mp3; original unchanged.
Delete SelectionDelRemoves the selection (Undo with Ctrl+Z).
Crop to SelectionCtrl+Shift+KKeeps only the selection.
Split at PositionCtrl+TTwo files _part1 and _part2.
Join FilesCtrl+JJoins files in the order you choose.
Insert Segment BoundaryMStarts a new segment at the position.

WAV and MP3 edits copy the original data directly (no re-encoding), so they are very fast and lose no quality. MP3 marks snap to MP3 frames (about 36 ms at 16 kHz). Edits never change the original until they have finished successfully.

Foot pedals and external devices

Options > External Devices replaces the old PC game port:

  • Game controllers (USB gamepads, joysticks, button boxes): any button, axis or hat.
  • USB foot pedals (HID): a built-in profile covers the VEC Infinity pedal; for others, select a mapping row, click Learn and press the pedal.
  • Serial ports: CTS, DSR, DCD and RI as inputs (e.g. a radio's squelch output with Record while active); DTR/RTS as outputs that follow Recording, Armed or Playing (e.g. an "on air" lamp). A switch between DTR and an input line registers as active.

Pedals that type keys can be bound in Hot-keys instead. Typical transcription setup: left = Rewind (hold), middle = Play while held, right = Fast Forward (hold).

Timed and scheduled recording

Control > Timed Recording records for a set time from now. Control > Schedule starts and stops recordings by itself (once, daily, weekdays, weekly or monthly), each with its own Vox, device, format and file names. Schedules run while the app is open or in the tray; if the PC was asleep, a recording starts late when no more than 5 minutes have passed.

Recordings can also stop by themselves after a period of silence or at a clock time (Options > Recording).

Command line

Use vrp.exe (next to VoiceRecorderPro.exe) from a Command Prompt, a script or a desktop shortcut:

vrp record --duration 0:30:00 --format wav     start recording (starts the app if needed)
vrp pause | vrp resume | vrp stop
vrp status --json
vrp play "C:\Recordings\Oct02_1.mp3" --from 1:20
vrp extract Oct02_1.mp3 --from 1:00 --to 2:30 --out clip.mp3
vrp split Oct02_1.mp3 --at 5:00
vrp join a.mp3 b.mp3 --out joined.mp3
vrp convert Oct02_1.wav --format flac
vrp devices
vrp schedule add --name Morning --start 2026-10-21T09:00 --duration 0:30:00 --repeat weekdays
vrp record --headless                           record without any window; Ctrl+C saves and stops

Exit codes: 0 ok, 1 usage error, 2 device error, 3 file error, 4 not running, 5 busy. Options > Recording > Run after each file is finished runs your own command with {path}, {duration_s}, {segments} and {start_iso}.

Troubleshooting

ProblemWhat to do
"Windows did not allow access to the microphone"Settings > Privacy & security > Microphone: turn on Let desktop apps access your microphone.
Meter does not move / "No signal"Check the device in Options > Sound Devices and use Test. Check the microphone is not muted in Windows Sound settings.
Computer audio meter stays emptyNothing is playing, or it plays on a device that is not the Windows default output (Settings > System > Sound > Output). Recording follows the default device within about 2 seconds of a change. Computer audio is too loud or quiet next to your voice: Options > Recording > Computer audio level.
Vox triggers on background noiseRaise the threshold or use Calibrate; enable the 80 Hz high-pass filter for rumble.
First words are cut offIncrease Pre-roll, or lower the threshold.
⚠ on the disk lineThe PC was too busy and some audio was lost. Choose a larger block size and "High" latency in Options > Advanced.
A hot-key shows "In use by another application"Pick a different combination.
Something elseHelp > Open Log Folder and look at vrp.log.

Settings live in %APPDATA%\VoiceRecorderPro\settings.json (Options has Export/Import); logs in %LOCALAPPDATA%\VoiceRecorderPro\Logs. Put an empty file called portable.flag next to the program to keep settings and logs beside it instead.
